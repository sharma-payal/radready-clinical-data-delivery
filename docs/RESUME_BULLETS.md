## Application paragraph

I built RadReady to model the work I would want to own at BioStack: turning an underspecified healthcare-AI request into a deliverable that a customer can actually accept. The project starts with use-case and rights questions, evaluates fictional providers, deliberately injects realistic data defects, quarantines failures, and packages a longitudinal radiology cohort with QC evidence and integrity checks. The key design choice was treating usefulness, licensing, communication, and acceptance as part of the data product—not downstream paperwork.
